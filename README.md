# Touareg — питомец для Windows

[Скачать приложение для Windows](https://github.com/nzyqjv9hgp-web/touareg-pet/releases/latest) · [Архив исходников](https://github.com/nzyqjv9hgp-web/touareg-pet/releases/latest/download/Touareg-Windows-source.zip)

Самостоятельное приложение для Windows 10/11 x64: прозрачная машина поверх рабочего стола, езда по верхним краям обычных окон, прыжки с рампы с окна на окно, падения с краёв, удары о стены экрана, езда по панели задач через все мониторы, перетаскивание мышью, бернаут с дымом и настоящий записанный V8. Первый запуск устанавливает файлы только в профиль текущего пользователя, создаёт ярлык на рабочем столе и открывает настройки. Администратор и отдельная установка .NET не нужны.

## Управление

- Щелчок по машине: быстрый старт.
- Удерживать левую кнопку на машине: она тормозит под курсором, через мгновение начинается бернаут на месте.
- Отпустить: быстрый старт. V8 продолжает звучать в поездке до полной остановки у края.
- Зажать левую кнопку и повести мышью: машина поднимается и висит на курсоре, раскачиваясь. Отпустить — бросок: она летит по инерции, отскакивает от краёв экрана и приземляется на окно или панель задач.
- Правая кнопка на машине или на значке рядом с часами: меню.
- Двойной щелчок по значку: размер, скорость, звук, автозапуск и обновления.
- «Вернуть питомца»: выбрать доступное окно заново.
- «Выход»: полностью завершить приложение.

## Поведение

- Окна: в конце окна машина ставит рампу и прыгает на соседнее окно впереди (выше или ниже). Если прыгать некуда, она разворачивается или съезжает с края и падает на то, что ниже.
- Стены: внешние края мониторов — стены. Машина врезается в них с дымом и отскоком и затем разворачивается. Брошенная машина тоже отскакивает от стен и потолка.
- Панель задач: машина ездит по нижнему краю рабочего стола и без остановки переезжает на соседний монитор. Если нижние края мониторов на разной высоте, она перепрыгивает или спрыгивает. Размер машины подстраивается под DPI монитора.
- С панели задач машина время от времени запрыгивает по рампе на окно над ней.
- Если окно под машиной закрыли, свернули или перекрыли, она падает вниз.
- Разворот: машина клюёт носом, подпрыгивает и разворачивается в воздухе. Рампа выдвигается перед прыжком и складывается после. Удары о стены и приземления слышны (эти звуки синтезируются в коде).

Плавность: окна читаются в фоновом потоке и сразу после того, как их двигают, сворачивают или перекрывают, поэтому машина едет вместе с перетаскиваемым окном. Кадры выдаются в такт обновлению экрана (до ~80 в секунду), кадры машины масштабируются один раз на размер и рисуются прямо в буфер окна.

Прозрачные участки пропускают клики. Эффекты размещены в отдельном слое, который пропускает все клики. Приложение не забирает фокус при езде. В полноэкранных играх/видео оно скрывается по умолчанию. При отсутствии подходящего верхнего края машина ездит над панелью задач. Для максимально раскрытого окна у верхнего края экрана места над заголовком нет; используется доступное другое окно или нижняя граница рабочего стола.

Геометрия окон читается локально. Текст окон, экран, клавиатурный ввод и документы не записываются и не отправляются. Сеть используется только для проверки и загрузки обновлений, когда подключён канал публикации.

## Сборка

Нужен .NET SDK 10.0. Приложение публикуется с включённой средой исполнения.

```powershell
./tools/build.ps1
```

На macOS/Linux тоже можно собрать EXE (запуск самого питомца требует Windows):

```text
dotnet run --project Checks/Checks.csproj -c Release
dotnet publish Windows/TouaregPet.csproj -c Release -r win-x64 --self-contained true -o dist
```

24 утверждённых кадра, колёса и звук встроены в EXE. Установка находится в `%LOCALAPPDATA%\TouaregPet`, настройки в `settings.json`, диагностика в `diagnostics.log`. Автозапуск включается пользователем и использует запись только в HKCU. Для удаления: выйти из приложения, отключить его автозапуск и удалить эту папку и ярлык.

Структура проекта: `Windows` — приложение и интеграция с рабочим столом, `Core` — движение, звук и проверка обновлений, `Assets` — кадры и записи V8, `Checks` — проверки, `tools` — сборка и подготовка подписанного релиза.

## Автообновление

По умолчанию включено. Первая проверка — через 30 секунд после запуска, дальше каждые 6 часов; есть ручная проверка в трее. Новый EXE загружается в отдельную папку версии. Подтверждаются RSA-3072/SHA-256 подпись манифеста, версия, размер и SHA-256 файла. Данные и конфигурация сохраняются отдельно. Новая версия включается при следующем запуске или через «Перезапустить для обновления».

Канал: [nzyqjv9hgp-web/touareg-pet](https://github.com/nzyqjv9hgp-web/touareg-pet) на GitHub. В этом репозитории находятся исходники, ресурсы и инструкции; готовые Windows-сборки опубликованы в Releases. В EXE встроен адрес канала и публичный ключ. Приватный ключ хранится отдельно и не включён в исходники, пользовательский пакет или репозиторий.

Адрес в `Assets/update-channel.json`:

```json
{"url":"https://github.com/nzyqjv9hgp-web/touareg-pet/releases/latest/download/update.json"}
```

Для новой версии повысить версию при сборке, сохранив этот публичный ключ, и подготовить подписанный манифест:

```text
dotnet run --project tools/ReleaseTool.csproj -- dist/TouaregPet.exe 1.1.0 https://github.com/nzyqjv9hgp-web/touareg-pet/releases/download/v1.1.0/TouaregPet.exe /private/path/update-signing-private.pem dist/update.json
```

При публикации прикрепить `TouaregPet.exe` и `update.json` к одному обычному GitHub Release. Последний обычный релиз определяет канал. Приватный ключ никогда не публиковать. Публичный ключ закреплён в сборке, подмена одного лишь адреса канала не позволяет установить неподписанный EXE.

При ручном запуске установщика 1.0.1 поверх ранней версии 1.0.0 выбирается новая версия и заполняется пустой адрес канала. Уже настроенный канал и настройки пользователя сохраняются. Старый ярлык продолжает запускать актуальную установленную версию.

## Проверено

Кросс-сборка Windows x64 успешно завершена; 55 проверок движения, перетаскивания и броска, ударов о стены, переезда между мониторами, прыжков с панели задач, разворота, рампы, масштаба, закрытия окон, PCM-звука, звуков ударов и защиты обновлений прошли. Ещё две проверки опубликованного EXE и встроенных ресурсов дают 57 проверок для релиза 1.1.0. Прозрачное окно, клики, трей, аудиоустройство, автозапуск и установка требуют отдельного прогона на реальной Windows. Такой прогон пока не выполнен: текущий компьютер — macOS.
