# Touareg — питомец для Windows

Мини-я на чёрном Touareg: ездит по краям окон, перепрыгивает на соседние окна и разворачивается. Удерживание ЛКМ — бернаут с дымом и настоящим V8; отпускание — быстрый старт.

[Скачать Windows-сборку](https://github.com/nzyqjv9hgp-web/touareg-pet/releases/latest)

Windows 10/11 x64. Распаковать архив и запустить TouaregPet.exe. Среда .NET включена. Управление и настройки доступны из значка рядом с часами. Программа устанавливается в профиль пользователя и автоматически получает подписанные обновления.

Первая сборка для проверки на ПК. Кросс-сборка и 32 программные проверки завершены; прозрачный слой, клики, звук и трей ещё требуют прогона на реальной Windows.

Звук: «Acceleration sounds of Ford V8 5 Liter engine» — noiseloop, [Freesound](https://freesound.org/people/noiseloop/sounds/455926/), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Запись нарезана, громкость выровнена, стыки сглажены; высота тона сохранена. NAudio — MIT, .NET — лицензии Microsoft. Уведомления включены в пакет.

Этот репозиторий предназначен для распространения сборок и канала обновлений. Исходный код и приватный ключ подписи здесь не публикуются.
