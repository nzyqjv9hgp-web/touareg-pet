# Touareg — питомец для Windows {VERSION}

Распакуй архив на Windows 10/11 (64-бит) и запусти **TouaregPet.exe**. Отдельная установка .NET и права администратора не нужны. При первом запуске появятся настройки и ярлык на рабочем столе.

- Щелчок по машине — быстрый старт.
- Удерживать левую кнопку — торможение, затем бернаут с дымом и настоящим V8. Отпустить — разгон; двигатель звучит до остановки.
- Зажать левую кнопку и потянуть — поднять машину. Отпустить — бросить её с инерцией.
- Машина прыгает с рампы между окнами, падает с краёв, отскакивает от стен экрана и ездит по панели задач между мониторами.
- В браузере (Chrome, Edge, Яндекс, Opera и др.) машина ездит по блокам открытой страницы. Отключается в настройках.
- Поднять машину и подержать неподвижно — колёса складываются, и она левитирует на реактивной тяге.
- Правая кнопка по машине или значку рядом с часами — меню. Двойной щелчок по значку — настройки размера, скорости, громкости, автозапуска и обновлений.
- «Вернуть питомца» выбирает доступное окно заново; «Выход» завершает приложение.

В полноэкранных играх и видео питомец скрывается по умолчанию. Прозрачные участки пропускают клики. При отсутствии места над обычными окнами машина ездит над панелью задач.

## Обновление

Если установлена более ранняя версия, выбери «Проверить обновления» в меню рядом с часами, дождись загрузки и выбери «Перезапустить для обновления». Можно также выйти из старой версии и запустить EXE из этого архива. Настройки сохраняются.

Автообновление включено по умолчанию: первая проверка через 30 секунд после запуска, далее каждые 6 часов. Подписанная версия загружается в фоне и включается при следующем запуске или через «Перезапустить для обновления».

## Проверено

EXE собран и проверен в GitHub Actions на Windows. Перед публикацией прошли все автоматические проверки, включая подпись манифеста и целостность готового файла (список — в `ПРОВЕРКИ.txt`), а также проверка на рабочем столе Windows: запуск 3D-рендера, перетаскивание машины мышью, бросок, приземление, щелчок, ховер и езда по блокам страницы в Edge.

Файлы находятся в `%LOCALAPPDATA%\TouaregPet`, настройки — в `settings.json`, диагностика — в `diagnostics.log`. Для удаления отключи автозапуск, выйди из приложения, удали эту папку и ярлык.
